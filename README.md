# Vac+ Frontend

Frontend do Vac+ composto por quatro aplicações independentes:

- `administradores/` — Administradores de Unidade
- `regional/` — Administradores Regionais
- `profissionais/` — Profissionais de Saúde
- `usuario/` — Cidadãos

Consulte [`LEIA-ME_INTEGRACAO.md`](./LEIA-ME_INTEGRACAO.md) para configurar `.env`, executar cada aplicação e entender o escopo e os limites da integração atual.

Cada aplicação também possui um `README_ENDPOINTS.md`, com os endpoints organizados por perfil, finalidade e situação (conectado, catalogado ou pendente de implementação no backend).
